# mouse —— 鼠标交互动画

这个文件夹集中存放**所有与鼠标交互动画相关**的逻辑和代码。
以后凡是改动这方面的内容，**只在这个文件夹里改即可**。

> 图片素材（Mouse1~4.png）和自定义指针（fish.ico / fish.png）放在 `frontend/public/`，
> 用根路径访问（如 `/Mouse1.png`）。这样同源、可用 canvas 读像素做像素级碰撞。

## 目录结构

```
frontend/
├── public/                 # 图片素材：Mouse1~4.png、fish.png（鼠标指针）
└── src/mouse/
    ├── follow/             # 第 1 个交互：鼠标跟随 + 剧情动画
    │   ├── Follow.jsx        # 组件本体（状态机：跟随→追逐→合体→等待→离场）
    │   ├── useImageData.js   # 读图片像素：非透明掩码 + 左下角锚点
    │   ├── pixelOverlap.js   # 两图非透明像素的接触检测
    │   └── follow.config.js  # 可调参数（手感、时长、间距、指针都在这里调）
    └── README.md
```

## follow 剧情动画（5 个阶段）

1. **跟随**：Mouse1 慢速跟随鼠标，按运动方向左右翻转，接触鼠标会抖动；动画期间鼠标换成自定义指针。
2. **追逐**：屏幕右边出现 Mouse2，冲向 Mouse1（方向实时跟随）。
3. **合体**：两图非透明像素接触 → Mouse1 变 Mouse3，按接触方向镜像对称地拉开间距、对齐水平线。
4. **等待**：保持几秒。
5. **离场**：Mouse3 变 Mouse4，和 Mouse2 保持间距一起移出屏幕、消失，鼠标恢复默认。

> 注：浏览器无法移动操作系统的真实鼠标指针（安全限制），
> 所以“接触时抖动”表现为图片自身抖动。所有手感参数见 `follow/follow.config.js`。

## 以后新增交互怎么做

在 `mouse/` 下再建一个子文件夹（例如 `mouse/chase/`），把对应组件和配置放进去；
图片素材统一放 `frontend/public/`，然后在页面里引入对应组件即可。
