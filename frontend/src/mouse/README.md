# mouse —— 鼠标交互动画

这个文件夹集中存放**所有与鼠标交互动画相关**的逻辑、图片和代码。
以后凡是改动这方面的内容，**只在这个文件夹里改即可**。

## 目录结构

```
mouse/
├── Image/                 # 所有动画用到的图片素材（Mouse1~4.png）
├── follow/                # 第 1 个交互：鼠标跟随
│   ├── Follow.jsx         # 组件本体（跟随 / 旋转对准 / 接触抖动）
│   ├── useImageAnchor.js  # 读取图片像素，找“左下角非透明像素”作为接触点
│   └── follow.config.js   # 可调参数（手感都在这里调）
└── README.md
```

## follow（鼠标跟随）效果说明

- 屏幕上显示 `Image/Mouse1.png`，它会一直**追着鼠标**移动；
- 图片**朝向始终对准鼠标**，鼠标移动时朝向随之改变（围绕“左下角接触像素”为支点旋转）；
- 当图片**左下角的非透明像素**接触到鼠标时，图片开始**随机抖动**；
- 鼠标移开后**停止抖动**，图片继续跟随。

> 注：浏览器无法移动操作系统的真实鼠标指针（安全限制），
> 所以“接触时抖动”表现为图片自身抖动。手感参数见 `follow/follow.config.js`。

## 以后新增交互怎么做

在 `mouse/` 下再建一个子文件夹（例如 `mouse/chase/`、`mouse/spin/`），
把对应的组件和配置放进去，图片仍统一放在 `mouse/Image/`，
然后在页面里引入对应组件即可。
